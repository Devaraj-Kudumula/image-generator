# Super-resolution models (OpenCV dnn_superres)

Place `.pb` model files here, or set `TRACE_SUPERRES_AUTO_DOWNLOAD=true` to fetch on first use.

| Model file     | `TRACE_SUPERRES_MODEL` |
|----------------|------------------------|
| FSRCNN_x2.pb   | FSRCNN_x2              |
| FSRCNN_x3.pb   | FSRCNN_x3              |
| EDSR_x4.pb     | EDSR_x4                |

Recommended for CPU servers: `FSRCNN_x3` (balance of speed and quality).
